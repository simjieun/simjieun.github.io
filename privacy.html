개인정보처리방침

Joy's Dev Tools · 시행일: 2026년 10월 20일

Joy's Dev Tools(이하 "앱")는 사용자의 개인정보를 소중히 여기며, Google 계정 연동 시 다음 원칙에 따라 데이터를 처리합니다.

1. 접근하는 정보

앱은 사용자가 Google OAuth 동의 화면에서 명시적으로 승인한 범위(scope)의 데이터에만 접근합니다. 승인하지 않은 정보에는 접근하지 않습니다.

2. 이용 목적

접근한 데이터는 사용자가 요청한 앱 기능을 제공하는 용도로만 사용합니다.

3. 저장 위치

모든 데이터는 사용자의 로컬 기기에만 저장됩니다. 앱은 별도의 외부 서버로 데이터를 전송하거나 보관하지 않습니다.

4. 제3자 제공

앱은 사용자의 데이터를 제3자에게 제공, 판매, 공유하지 않으며 광고 목적으로 사용하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

6. 접근 권한 철회

사용자는 언제든지 Google 계정 권한 설정에서 앱의 접근 권한을 철회할 수 있습니다. 로컬에 저장된 데이터는 앱 또는 해당 파일을 삭제하여 제거할 수 있습니다.
